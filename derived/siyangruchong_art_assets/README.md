# 《饲养蠕虫》(worm-capitalist) 全量美术与多媒体资源归档

本项目所有提取出的美术与多媒体资源已完整整理至本文件夹中：

## 目录结构
- `Sprites/`: **220** 个独立游戏精灵（PNG 格式，包含各个阶段的蠕虫外观、面包屑/豌豆/饼干/汉堡等全部食物、主动技能图标、金币、商店控件等）。
- `Textures/`: **151** 张原始贴图（PNG 格式，包含全分辨率图集 Atlas、木桌台面背景、各种光照遮罩与环境特效纹理）。
- `Fonts/`: **3** 款字体（TTF 格式，包含游戏中使用的像素字体 PerfectDOSVGA437 与黑体等）。
- `Audio/`: **59** 条完整音频（WAV 格式，包含背景音乐 BGM、蠕虫进食咀嚼音效、金币获取、技能音效等）。
- `WebTemplate/`: **7** 个网页与启动图标资产（包含游戏官方高清 Icon、载入条等）。
