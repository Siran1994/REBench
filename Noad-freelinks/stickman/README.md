# Stickman Maze Run (火柴人迷宫跑酷) - 网页版无广告试玩链接 (No-Ad Free-Link)

本目录为专用于 **CDN 上传** 和 **Web 浏览器直接运行** 的免广告网页版工程。已整合**完整中文本地化翻译**、**中文字体**与**音效修复**成果。

---

## 特性说明

1. **全链路广告拦截与秒发奖励**：
   - **PokiSDK (`rewardedBreak` / `commercialBreak`)**：已注入全链路免广告拦截垫片（`noad-bridge.js`），关卡跳关（Skip）、结算翻倍、皮肤解锁等点位点击直接秒发奖励！
   - **商业广告跳过**：插屏广告与关卡切换广告自动跳过，保障畅快连续游玩。
   - 触发时屏幕上方弹出毛玻璃免广告提示（HUD Toast）：`✨ [免看广告] 奖励已直接发放！`
2. **全量中文本地化 (zh)**：
   - 内置通用中文字体 `font.ttf`，字体大小度量与基线已全面修正，消除排版偏移。
   - 全量汉化主菜单（1P 剧情模式、2P 双人合作、2P 双人对决、在线速通、抓人模式、竞速模式等）、全部 138 个关卡世界、结算面板、皮肤商店与动态通关赞美词。
   - 首页模式选择立方体文字（1P / 2P）居中优化。
   - 关卡内功能按钮布局优化，排布于左上角，清爽整齐。
3. **原生 Web 兼容性与音效全解锁**：
   - 43 个高品质 WebM 游戏音效与背景音乐全部就绪。
   - 集成首触音频自动解锁（Web Audio Touch Unlocker）。
   - 纯相对路径，无跨域与本地绝对路径硬编码，直接上传至任意对象存储桶或 CDN 即可访问。
4. **防缓存冲突与安全保护**：
   - 内置安全 Service Worker 清道夫，自动注销陈旧缓存，规避页面更新滞后。
   - 包含文件协议防护，提示使用 Web 静态服务运行以防止浏览器本地 CORS 拦截。

## 本地预览测试

进入当前项目目录，启动静态 Web 服务器：

```bash
# 方式 1: 直接双击运行
双击运行当前目录下的「启动网页试玩.bat」

# 方式 2: 使用 Python 命令行
python serve.py 8092
```

浏览器访问 `http://localhost:8092/index.html` 即可开始试玩。

---

## CDN 部署步骤

1. 将当前文件夹内的所有文件完整上传至 CDN 静态存储桶（如阿里云 OSS、腾讯云 COS、AWS S3、Cloudflare Pages 等）的目标子目录，例如：
   `https://cdn.example.com/games/stickman/`
2. 确保存储桶的默认首页设为 `index.html`，且对 `.wasm` 配置 `application/wasm`、对 `.js` 配置 `application/javascript`。
3. 复制生成的链接即可直接分发免广告试玩！
